# Base64 Decoder
A simple, user-friendly web interface that allows users to enter a Base64-encoded message and decode it into readable text.

## Features
- Decode Base64-encoded messages.
- Simple and intuitive user interface.
- Instant decoding.
- No external libraries required.

## Technologies Used
- **HTML5** – Structure of the interface.
- **CSS3** – Styling and layout.
- **JavaScript** – Base64 decoding functionality using the built-in `atob()` method.

## How to Use
1. Clone this repository:

   ```bash
   git clone https://github.com/USERNAME/base64_decoder.git
   ```

2. Navigate to the project directory:

   ```bash
   cd base64_decoder.git
   ```

3. Open `index.html` in your browser.

4. Enter your Base64-encoded message.

5. Click the Decode button to view the decoded result.

## Example

**Encoded message:**
```text
SGVsbG8gV29ybGQ=
```

**Decoded result:**
```text
Hello World
```

## Note

Base64 is an encoding method, not encryption. It does not provide security or protect sensitive information.
